# API PIPELINE

Open **index.html** in a browser. This is a self-contained black-and-gold interface prototype, not a connected execution service.

The interface contains API group home pages, Run/Settings/Results/Backside views, reorderable template sections, Python placeholders, ordered workflows, seven HTML assembly companions, and an HTML review queue. Run plays a labeled sample activity log; it does not send API requests or save generated answers to disk.

- **START HERE.md**: continuation prompt, agreed behavior, and implementation boundaries.
- **HTML ASSEMBLIES.md** and **assembly-definitions.json**: assembly station design and editable layout defaults.
- **IMPORTER - FEASIBILITY.md**: read-only importer assessment based on existing station definitions.
- **CLASSIFIER AND RESEARCH - REVIEW.md**: assessment and corrections to the supplied design discussion.
- **Auto Paper Classifier Design - ORIGINAL.docx**: preserved source discussion, not an implementation specification.

Session edits reset on reload. Use the mockup's download controls to retain edited templates, configuration, and logs. Folder paths and progress are examples. Existing API station source is unchanged.
