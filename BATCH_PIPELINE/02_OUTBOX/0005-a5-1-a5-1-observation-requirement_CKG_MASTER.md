## At a glance
This is a canonical axiom record (A5.1) stating an ontological stance: observation is constitutive of actuality. It matters because it posits a fundamental requirement for reality, influencing interpretations in physics and philosophy. The one-sentence finding is that nothing is considered actual unless it is observed.

## Central claim
For any entity x, if x is actual, then there exists an observer O such that O observes x. Formally: ∀x: Actual(x) → ∃O: Observes(O, x).

## Best concise argument
1. Actuality is not a property that exists independently.
2. Observation is the process that confers the status of "actual" upon an entity.
3. Therefore, for any entity to be actual, it must be observed.
4. This is a foundational stance, not derived from other axioms but posited as a core root dependency.
