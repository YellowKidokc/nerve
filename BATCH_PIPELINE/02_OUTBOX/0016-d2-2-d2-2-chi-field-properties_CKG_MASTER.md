* **Scalar field:** A field described by a single number (magnitude) at each point in space and time, unlike a vector (which has direction) or tensor (which has multiple components and directions). *Analogy:* Temperature across a room is a scalar field; the wind velocity is a vector field.
* **Lorentz-invariant:** A property that does not change when viewed from different inertial reference frames moving at constant relative velocities (the core symmetry of Special Relativity). *Analogy:* The speed of light is Lorentz-invariant; it's measured as the same value by all observers.
* **Self-Grounding (A2.2):** The concept that a system contains its own reason for existence or justification, requiring no external foundation. *Analogy:* A dictionary that defines every word using only other words within the same dictionary.
